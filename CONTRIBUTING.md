# Contributing to EmailZit

Thank you for helping! EmailZit is free software under the GNU AGPLv3.

## Questions, bugs and ideas

- **Bugs:** open an [issue](https://github.com/Max-Zit/emailzit/issues) with the EmailZit version, what you did, what happened and what you expected.
- **Ideas:** open an issue that describes the problem you want to solve, or start a [discussion](https://github.com/Max-Zit/emailzit/discussions).
- **Security problems:** do not open a public issue; see [SECURITY.md](SECURITY.md).

## Code

Development happens on the `develop` branch; `main` holds released versions. Keep changes focused, with tests for new behavior. New dependencies must have a license compatible with the AGPLv3.

By contributing you agree that your contribution is licensed under the GNU AGPLv3.
