Začínáme

EmailZit je hosting pošty pro mnoho domén a zákazníků na vašem vlastním serveru: administrátorský panel pro personál serveru, zákaznický panel, ve kterém každý zákazník spravuje své vlastní domény a schránky, a stránky pro uživatele pošty (webmail, vlastní heslo, hesla aplikací, automatická odpověď, filtry).

Jak je sestaven

  • Server EmailZit — panely a REST API, běžící pod neprivilegovaným uživatelem.
  • Postfix přijímá a odesílá poštu (SMTP na portu 25, odesílání pro poštovní programy na 465 a 587, vždy šifrované).
  • Dovecot ukládá poštu a poskytuje IMAP (993) a POP3 (995).
  • PostgreSQL uchovává vše, co panely mění; Postfix a Dovecot z ní čtou přímo, takže nová schránka funguje okamžitě, aniž by bylo nutné cokoli restartovat.
  • Malý root pomocník dělá těch několik věcí, které vyžadují root (poštovní adresáře, certifikáty, aktualizace); každý požadavek je zkontrolován a zapsán do protokolu auditu.

Instalace

  • Appliance — hotový virtuální stroj (OVA pro VMware ESXi a Workstation, qcow2 pro Proxmox VE a KVM, VHDX pro Hyper-V generace 1) nebo instalační ISO pro nový VM nebo fyzický server (smaže první disk). Přidělte mu alespoň 2 CPU, 2 GB paměti a disk pro poštu (kořenový souborový systém se sám zvětší, když se zvětší virtuální disk). Po prvním spuštění zobrazí obrazovka adresu panelu a token pro nastavení; přihlášení na obrazovce jako ezadmin (první heslo emailzit, musí se změnit) otevře nabídku nastavení: síť (pro poštovní server použijte pevnou adresu), název serveru, časové pásmo, adresa panelu a token pro nastavení, heslo účtu personálu, stav služeb, restart.
  • Balíček pro Debian 13 — sudo sh install.sh z vydání, nebo .deb pomocí apt install: nainstaluje Postfix, Dovecot, Rspamd, Valkey a PostgreSQL z Debianu a vše nastaví.
  • Porty: 25 (pošta z jiných serverů), 465 a 587 (odesílání z poštovních programů), 993 (IMAP), 995 (POP3), 8444 (panely a webmail) a 443 a 80 pro automatické nastavení poštovních programů (autoconfig pro Thunderbird, Autodiscover pro Outlook, zásada MTA-STS; vše ostatní tam vede na webmail). EmailZit používá 443 a 80 jen tehdy, když není nainstalován žádný webový server a HostZit není propojen; jinak pro tato jména odpovídá webový server HostZit (--public-web off to vypne). Server potřebuje reverzní DNS název (PTR), který odpovídá jeho poštovnímu názvu hostitele, a odchozí port 25 musí být otevřený.

Kdo smí co

  • Správci spravují server, účty personálu, balíčky a všechny zákazníky. Operátoři spravují zákazníky, domény a schránky; pozorovatelé se jen dívají.
  • Zákazníci vidí a mění jen své vlastní domény, schránky, aliasy a přeposílání, v rámci limitů svého balíčku.
  • Uživatelé pošty se přihlašují svou adresou, svým heslem a vždy druhým faktorem (ověřovací aplikací). Poštovní programy (Outlook, Thunderbird, telefony) toto heslo nikdy nepoužívají: každý program dostane své vlastní heslo aplikace.

První kroky

  1. Nastavte název hostitele serveru v Nastavení → Poštovní server (název, ke kterému se poštovní programy připojují, např. mail.example.com).
  2. Vytvořte balíček s limity, které prodáváte (domény, schránky, úložiště, odesílání za hodinu).
  3. Vytvořte zákazníka s tímto balíčkem a dejte zákazníkovi přihlášení do panelu.
  4. Přidejte doménu zákazníka, vložte záznamy DNS zobrazené na stránce domény u poskytovatele DNS domény a doménu ověřte.
  5. Vytvořte schránky. Uživatel pošty se přihlásí na /mail, nastaví druhý faktor a vytvoří hesla aplikací pro své programy.
