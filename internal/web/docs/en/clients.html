Setting up mail programs

Step 1: an app password

  1. Open https://<server>:8444/mail and sign in with your address and password.
  2. The first time, set up two-factor sign-in: scan the QR code with an authenticator app and keep the recovery codes.
  3. Under App passwords give the program or device a name (for example "Outlook on the laptop") and create the password. Enter it in the program right away: it is shown only once.

Step 2: the program

Most programs (Outlook, Thunderbird, iOS and Android mail apps) find the settings by themselves when you enter only the address and the app password. Otherwise use:

User namethe full e-mail address
Incoming (IMAP)the server's host name, port 993, SSL/TLS
Incoming (POP3)the server's host name, port 995, SSL/TLS
Outgoing (SMTP)the server's host name, port 465 SSL/TLS or 587 STARTTLS, sign-in required

The mailbox page in the panels shows these values with the real host name.
