Webmail and the mail user's pages

Every mail user has their own pages at https://<mail host>:8444/mail (on a standalone server https://<mail host>/ leads there too). They are separate from the panels: a mail user never sees other mailboxes, the customer's settings or the server.

Signing in

  • The address and the mailbox's password, and always a second factor: at the first sign-in the user scans a QR code with an authenticator app (Google Authenticator, Microsoft Authenticator, Aegis …) and keeps the recovery codes.
  • A user who lost the phone and the recovery codes asks the provider: staff and the customer can reset the second factor on the mailbox page; the user sets it up again at the next sign-in.
  • The language of the pages follows the user's choice (top right) and is remembered.

Webmail

  • Folders on the left (on a phone at the top): Inbox, Drafts, Sent, Archive, Junk, Trash and the user's own folders, with the number of unread messages.
  • The list shows sender, subject and date; unread messages are bold. Select messages to mark them read or unread, move them to Junk (to keep a sender out for good, add it to the blocked senders) or delete them (to Trash; deleting in Trash removes them). Move puts the selected messages (or the open one) into another folder.
  • Search finds the words anywhere in the messages of the open folder (headers and text).
  • Messages written in HTML are shown in a protected frame: scripts, forms and remote images are never loaded, so opening a message cannot tell the sender anything. Attachments are downloaded, never opened in the browser.
  • Write, Reply, Reply to all and Forward send through the server like a mail program does (with the mailbox's sending limits and DKIM signature); a copy goes to Sent. Attachments up to the server's message size can be added. While writing, the address fields suggest the contacts; the signature is already under the text.

Contacts and signature

  • Contacts: the address book of webmail. Addresses mail is sent to from webmail are added by themselves (with the name written in the message); the user can add, rename (save the same address with a new name) and remove entries.
  • Signature: a text webmail puts under every new message, reply and forward. Mail programs have their own signature setting.
  • When the mailbox reaches 80 % and 95 % of its quota, a warning from the server arrives in the Inbox.

My mailbox

  • Usage: how much of the quota is used.
  • Password: the user changes the web password here (at least 12 characters).
  • App passwords: one per program or device, shown once when created; a lost device means deleting its app password. The page also shows the settings for mail programs and offers an Apple profile (.mobileconfig) for iPhone, iPad and Mac.

Auto-reply and filters

  • Auto-reply: a text (and optional subject) sent to senders while it is on, optionally only between two dates; the same sender gets it again only after the chosen number of days. Mailing lists, automatic messages and spam never get an auto-reply.
  • Filters sort incoming mail: when the sender, the recipients or the subject contain a text, move the message to a folder, mark it read or delete it. The first matching filter decides.
  • Spam: how much spam goes to Junk (or the level of the whole account), and the user's own allowed senders (never Junk) and blocked senders (always Junk).
