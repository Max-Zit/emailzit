Configurer les logiciels de messagerie

Étape 1 : un mot de passe d'application

  1. Ouvrez https://<server>:8444/mail et connectez-vous avec votre adresse et votre mot de passe.
  2. La première fois, configurez la connexion à deux facteurs : scannez le code QR avec une application d'authentification et conservez les codes de récupération.
  3. Sous Mots de passe d'application, donnez un nom au logiciel ou à l'appareil (par exemple « Outlook sur le portable ») et créez le mot de passe. Saisissez-le immédiatement dans le logiciel : il n'est affiché qu'une seule fois.

Étape 2 : le logiciel

La plupart des logiciels (Outlook, Thunderbird, les applications de messagerie iOS et Android) trouvent les paramètres d'eux-mêmes lorsque vous saisissez uniquement l'adresse et le mot de passe d'application. Sinon, utilisez :

Nom d'utilisateurl'adresse e-mail complète
Entrant (IMAP)le nom d'hôte du serveur, port 993, SSL/TLS
Entrant (POP3)le nom d'hôte du serveur, port 995, SSL/TLS
Sortant (SMTP)le nom d'hôte du serveur, port 465 SSL/TLS ou 587 STARTTLS, authentification requise

La page de la boîte aux lettres dans les panneaux affiche ces valeurs avec le vrai nom d'hôte.
