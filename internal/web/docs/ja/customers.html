顧客とパッケージ

パッケージ

パッケージには顧客に与える制限が含まれます。ドメイン、メールボックス、エイリアスの数、全メールボックスで合計して使える容量、新しいメールボックスのサイズと最大のメールボックスのサイズ、そして送信制限です。課金システムはパッケージを短い名前（例：business-10）で参照します。

  • 1 時間 / 1 日あたりのメッセージ（メールボックスごと）と顧客全体での 1 時間あたりの制限は、サーバーのアドレスの評判を守ります。パスワードを盗まれたメールボックスでも、何千通ものスパムを送ることはできません。制限を超えたメッセージはキューで待機します。
  • 1 通あたりの宛先数は、1 通のメッセージが何千ものアドレスに送られるのを防ぎます。
  • 顧客をより小さなパッケージに変更しても何も削除されません。新しい制限を超える追加ができなくなるだけです。

顧客

顧客はドメインとメールボックスを所有します。各顧客のメールは専用のシステムユーザーのもとに保存されるため、メールソフトウェアに不具合があっても、ある顧客が別の顧客のメールを読むことはできません。顧客が別の顧客のメールボックスにメールを回したり、その顧客のアドレスとして送信したり、その顧客のドメインを見たりすることは決してできません。

  • パネルのログイン：顧客は管理パネルと同じアドレスで顧客パネルにサインインします。各ログインは初回サインイン時に 2 段階サインインを設定する必要があります。
  • 課金 ID：お使いの課金システムでの顧客番号です。REST API はこの番号で顧客を検索します。
  • 送信元アドレス（サーバーに追加の送信用アドレスがある場合。「スタッフ、設定、更新」を参照）：顧客のメールは専用の IP アドレスとホスト名から送信されるため、送信の評判はその顧客自身のものになります。その後、顧客の各ドメインに表示される SPF レコードを公開してください。

停止と解約

  • 停止中：顧客のドメイン宛のメールは引き続き受信されます（何も失われません）が、その顧客の誰もサインイン、メールソフトの使用、送信ができません。セッションは直ちに終了します。
  • 解約済み：顧客のドメイン宛のメールは拒否されます。データは削除されるまで残ります。
  • 有効化で、停止中または解約済みの顧客を元に戻します。
