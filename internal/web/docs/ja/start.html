はじめに

EmailZit は、ご自身のサーバーで多数のドメインと顧客にメールホスティングを提供します。サーバーのスタッフ向けの管理パネル、各顧客が自分のドメインとメールボックスを管理する顧客パネル、そしてメールユーザー向けのページ（Web メール、ご自身のパスワード、アプリパスワード、自動返信、フィルター）があります。

構成

  • EmailZit サーバー — パネルと REST API です。特権のないユーザーとして動作します。
  • Postfix はメールを受信・送信します（ポート 25 の SMTP、メールソフトからの送信用に 465 と 587。常に暗号化されます）。
  • Dovecot はメールを保存し、IMAP（993）と POP3（995）を提供します。
  • PostgreSQL はパネルで変更されるすべてのデータを保持します。Postfix と Dovecot はこれを直接読み取るため、新しいメールボックスは何も再起動せずにすぐ使えます。
  • 小さなroot ヘルパーが root 権限を必要とする数少ない処理（メールディレクトリ、証明書、アップデート）を行います。すべてのリクエストは検査され、監査ログに記録されます。

インストール

  • アプライアンス — すぐに使える仮想マシン（VMware ESXi と Workstation 用の OVA、Proxmox VE と KVM 用の qcow2、Hyper-V 第 1 世代用の VHDX）、または新しい VM や物理サーバー用のインストーラー ISO（最初のディスクを消去します）です。CPU 2 個以上、メモリ 2 GB 以上、メール用のディスクを割り当ててください（仮想ディスクを拡張すると、ルートファイルシステムは自動的に拡張されます）。初回起動後、画面にパネルのアドレスとセットアップトークンが表示されます。画面上で ezadmin としてサインインすると（初期パスワードは emailzit、変更が必要です）、セットアップメニューが開きます。ネットワーク（メールサーバーには固定アドレスを使用してください）、サーバー名、タイムゾーン、パネルのアドレスとセットアップトークン、スタッフアカウントのパスワード、サービスの状態、再起動を設定できます。
  • Debian 13 パッケージ — リリースの sudo sh install.sh、または .deb を apt install でインストールします。Debian から Postfix、Dovecot、Rspamd、Valkey、PostgreSQL をインストールし、すべてを設定します。
  • ポート：25（他のサーバーからのメール）、465 と 587（メールソフトからの送信）、993（IMAP）、995（POP3）、8444（パネルと Web メール）、そしてメールソフトの自動設定用の 443 と 80（Thunderbird 用の autoconfig、Outlook 用の Autodiscover、MTA-STS ポリシー。それ以外はすべて Web メールに移動します）。EmailZit が 443 と 80 を使うのは、Web サーバーがインストールされておらず HostZit とも連携していない場合だけです。連携している場合は HostZit の Web サーバーがこれらの名前に応答します（--public-web off でオフにできます）。サーバーにはメールのホスト名と一致する逆引き DNS（PTR）名が必要で、送信方向のポート 25 が開いている必要があります。

誰が何をできるか

  • 管理者はサーバー、スタッフアカウント、パッケージ、すべての顧客を管理します。オペレーターは顧客、ドメイン、メールボックスを管理します。閲覧者は閲覧のみです。
  • 顧客は、パッケージの制限内で、自分のドメイン、メールボックス、エイリアス、転送だけを表示・変更できます。
  • メールユーザーは、アドレス、パスワード、そして常に 2 つ目の要素（認証アプリ）でサインインします。メールソフト（Outlook、Thunderbird、スマートフォン）はこのパスワードを使いません。ソフトごとに専用のアプリパスワードを使います。

最初の手順

  1. 設定 → メールサーバーでサーバーのホスト名を設定します（メールソフトが接続する名前。例：mail.example.com）。
  2. 販売する制限（ドメイン、メールボックス、容量、1 時間あたりの送信数）を持つパッケージを作成します。
  3. そのパッケージで顧客を作成し、顧客にパネルのログインを発行します。
  4. 顧客のドメインを追加し、ドメインのページに表示される DNS レコードをドメインの DNS プロバイダーに登録して、ドメインを確認します。
  5. メールボックスを作成します。メールユーザーは /mail でサインインし、2 つ目の要素を設定して、使用するソフト用のアプリパスワードを作成します。
