Webメールとメールユーザーのページ

各メールユーザーには https://<mail host>:8444/mail に専用のページがあります（スタンドアロンのサーバーでは https://<mail host>/ からもアクセスできます）。これらはパネルとは別のページで、メールユーザーが他のメールボックス、顧客の設定、サーバーを見ることはありません。

サインイン

  • アドレスとメールボックスのパスワード、そして常に 2 つ目の要素が必要です。初回サインイン時に、ユーザーは認証アプリ（Google Authenticator、Microsoft Authenticator、Aegis …）で QR コードをスキャンし、リカバリーコードを保管します。
  • スマートフォンとリカバリーコードの両方を失ったユーザーはプロバイダーに依頼します。スタッフと顧客はメールボックスのページで2 段階サインインをリセットでき、ユーザーは次回のサインイン時に再設定します。
  • ページの言語はユーザーの選択（右上）に従い、記憶されます。

Web メール

  • フォルダーは左側（スマートフォンでは上部）にあります。受信トレイ、下書き、送信済み、アーカイブ、Junk、ごみ箱、ユーザー自身のフォルダーで、未読メッセージの数が表示されます。
  • 一覧には送信者、件名、日付が表示され、未読のメッセージは太字です。メッセージを選択して、既読・未読にしたり、Junk に移動したり（送信者を完全に締め出すには、ブロックする送信者に追加します）、削除したり（ごみ箱へ。ごみ箱で削除すると完全に消去されます）できます。移動は、選択したメッセージ（または開いているメッセージ）を別のフォルダーに移します。
  • 検索は、開いているフォルダーのメッセージ内（ヘッダーと本文）のどこにある語句でも見つけます。
  • HTML で書かれたメッセージは保護されたフレームに表示されます。スクリプト、フォーム、外部の画像は決して読み込まれないため、メッセージを開いても送信者に何も伝わりません。添付ファイルはダウンロードされ、ブラウザーで開かれることはありません。
  • 作成、返信、全員に返信、転送は、メールソフトと同じようにサーバー経由で送信します（メールボックスの送信制限と DKIM 署名が適用されます）。コピーは送信済みに入ります。サーバーのメッセージサイズまでの添付ファイルを追加できます。作成中は、アドレス欄に連絡先が候補として表示され、本文の下にはすでに署名が入っています。

連絡先と署名

  • 連絡先：Web メールのアドレス帳です。Web メールから送信した宛先のアドレスは自動的に追加されます（メッセージに書かれた名前付きで）。ユーザーはエントリーを追加、名前の変更（同じアドレスを新しい名前で保存）、削除できます。
  • 署名：Web メールが新しいメッセージ、返信、転送のすべての下に挿入するテキストです。メールソフトには独自の署名設定があります。
  • メールボックスがクォータの 80 % と 95 % に達すると、サーバーからの警告が受信トレイに届きます。

マイメールボックス

  • 使用量：クォータのうちどれだけ使用しているかです。
  • パスワード：ユーザーはここで Web 用のパスワードを変更します（12 文字以上）。
  • アプリパスワード：ソフトまたは端末ごとに 1 つで、作成時に 1 回だけ表示されます。端末を紛失したら、そのアプリパスワードを削除します。このページにはメールソフト用の設定も表示され、iPhone、iPad、Mac 用の Apple プロファイル（.mobileconfig）も提供されます。
  • メールサーバーの管理者が質問に答えるためにこのメールボックスを開いた場合、その日時がここに表示されます。

自動返信とフィルター

  • 自動返信：オンの間に送信者へ送られるテキスト（と任意の件名）です。2 つの日付の間だけに限定することもできます。同じ送信者には、選択した日数が経過してから再び送られます。メーリングリスト、自動送信メッセージ、スパムには自動返信は送られません。
  • フィルターは受信メールを振り分けます。送信者、宛先、件名に特定のテキストが含まれる場合に、メッセージをフォルダーに移動する、既読にする、または削除します。最初に一致したフィルターが適用されます。
  • 迷惑メール：どの程度のスパムを Junk に入れるか（またはアカウント全体のレベル）、およびユーザー自身の許可する送信者（Junk にしない）とブロックする送信者（常に Junk）です。
