客户和套餐

套餐是单个邮箱的方案

套餐是单个邮箱的方案（Mail 10、Mail 100 …）：新邮箱的容量、允许的最大容量，以及每小时和每天可以发送多少。邮件按邮箱出售，所以一个客户可以同时拥有多个方案 — 例如三个 Mail 10、两个 Mail 100 和一个 Mail 25。计费系统用短名称引用套餐（例如 mail-10）。

每个客户另有一个基础套餐。它包含适用于整个客户的内容：多少个域名和别名、所有邮箱合计可使用多少空间、客户每小时可发送多少、一封邮件可以有多少收件人。新客户从基础套餐所包含的邮箱数量开始。

  • 客户页面上的邮件方案显示客户拥有每个方案的多少个邮箱，以及其中多少个已在使用。只要某个方案还有空位，就可以新建邮箱，它会获得该方案的容量和发送限制；员工之后可以把邮箱移到另一个方案。REST API 用 PUT /api/v1/customers/{id}/mailbox-packages 写入订购的内容。
  • 每小时和每天的邮件数来自邮箱自己的方案，整个客户每小时来自基础套餐。它们保护服务器地址的声誉：密码被盗的邮箱也无法发送成千上万封垃圾邮件。超出限制的邮件在队列中等待。
  • 每封邮件的收件人数可防止一封邮件发往成千上万个地址。
  • 只有当某个方案不再有邮箱时才能将它移除；仍有邮箱的套餐无法删除。

客户

客户拥有域名和邮箱。每个客户的邮件都存储在其专属系统用户下，因此即使邮件软件出现故障，也不会让一个客户读取另一个客户的邮件。客户永远无法将邮件路由到另一个客户的邮箱、以其地址发送邮件或查看其域名。

  • 面板登录：客户在与管理面板相同的地址登录客户面板。每个登录在首次登录时都必须设置双重验证登录。
  • 计费 ID：客户在您的计费系统中的编号；REST API 通过它查找客户。
  • 出站地址（当服务器有额外的出站地址时，参见“员工、设置和更新”）：客户的邮件从其专属的 IP 地址和主机名发出，因此其发送信誉只属于它自己。之后请发布客户每个域名上显示的 SPF 记录。

暂停和终止

  • 已暂停：客户域名的邮件仍会被接收（不会丢失任何内容），但该客户的任何人都无法登录、使用邮件程序或发送邮件。会话会立即结束。
  • 已终止：拒收客户域名的邮件。数据会一直保留，直到被删除。
  • 激活可恢复已暂停或已终止的客户。
